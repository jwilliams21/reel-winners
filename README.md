# 🎬 Reel Winners

A modern movie discovery and tracking application designed to help film enthusiasts explore Academy Award history, track watched cinema classics, and gamify their watchlists.

---

## 💡 Motivation & Overview

While thousands of incredible films exist, many movie lovers miss out on legendary Oscar winners and timeless classics simply because they don't know they exist or haven't kept track. 

**Reel Winners** solves this by providing interactive watchlists for major Oscar winners by year alongside a curated list of the Top 100 Movies of All Time. To boost engagement, the app tracks progress and awards users dynamic **Watcher Tiers** based on how many cinematic masterpieces they’ve completed.

---

## ✨ Key Features

* **🏆 Oscar Winner Showcase:** Browse major Academy Award winners filtered dynamically by year.
* **💯 Top 100 Movies Checklist:** Track viewings against a curated list of the greatest films of all time.
* **✅ Interactive Tracking:** Mark movies as watched with real-time progress state.
* **⭐ Watcher Tiers & Gamification:** Unlock higher user tiers as your watched list grows—from casual viewer to cinema connoisseur.
* **⚡ Modern UI & Responsive Design:** Fast, clean, visual layout optimized across desktop and mobile views.

---

## 🛠️ Tech Stack

* **Frontend:** React, JavaScript (ES6+)
* **Styling:** Tailwind CSS
* **Build Tool:** Vite (with React Compiler)
